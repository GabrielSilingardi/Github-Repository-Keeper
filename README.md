# GitHub Wiki

Aplicacao React para pesquisar e listar repositorios do GitHub.

## Desenvolvimento

Instale as dependencias:

```bash
npm install
```

Inicie o servidor do Vite:

```bash
npm run dev
```

A aplicacao fica disponivel em `http://localhost:5173`.

## Build

Gere os arquivos de producao:

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```
